LineageOS 23.2 (Android 16 QPR2) requirements for this kernel
============================================================

1) eBPF / ro.bpf.kver_override
-----------------------------
This kernel carries a 5.10-level eBPF backport (including BPF_MAP_TYPE_RINGBUF
and ringbuf helpers) suitable for:

  ro.bpf.kver_override=5.10.239

Set this in the device tree product properties (product.prop / system.prop),
matching official LineageOS sm8150 devices, for example:

  # eBPF
  ro.bpf.kver_override=5.10.239

Without the matching kernel features, bpfloader will fail when loading
5.10+ maps/programs (ringbuf, LMKD/AMS hooks, etc.).

2) Lineage Health charging control
----------------------------------
Sysfs node (implemented by OPLUS charger on power_supply "battery"):

  /sys/class/power_supply/battery/mmi_charging_enable

  - read:  0 = charging disabled (mmi), 1 = charging enabled
  - write: 0 = stop charging, 1 = allow charging

Device tree should set:

  $(call soong_config_set,lineage_health,charging_control_charging_path,/sys/class/power_supply/battery/mmi_charging_enable)

Implementation path in this tree:
  - include/linux/power_supply.h: POWER_SUPPLY_PROP_MMI_CHARGING_ENABLE
  - drivers/power/supply/power_supply_sysfs.c: mmi_charging_enable attr
  - drivers/power/oppo/oplus_charger.c: get/set/writeable handlers
  - drivers/power/oppo/charger_ic/oplus_battery_msm8150Q.c: battery psy props

Requires VENDOR_EDIT + OPLUS_FEATURE_CHG_BASIC (via OplusKernelEnvConfig.mk)
and CONFIG_OPLUS_SM8150R_CHARGER=y (samurai_defconfig).
